# 🇷🇺 RU-Proxy + Mini Backend

Прокси-сервер для обхода гео-блока российских видеоплееров (Kodik, Collaps,
VideoCDN, VideoFrame…) + центральный мини-бэкенд приложения. Нужен, чтобы
пользователи приложения, сидящие в Telegram через VPN (зарубежный IP), всё
равно могли смотреть русские озвучки: прокси запрашивает плеер со своего
российского IP и отдаёт контент пользователю.

## Возможности

| Маршрут | Что делает |
|---|---|
| `/?url=<encoded>` | Прокси плееров (запрос с рф IP, обход гео-блока) |
| `GET /api/config` | Публичный конфиг: реклама, объявление, реквизиты, цены, премия |
| `POST /api/premium/claim` | Оплата → автоматическая выдача премиума |
| `POST /api/premium/check` | Проверка премиума по нику |
| `POST /api/mod/login` | Вход модератора по имени |
| `GET/POST /api/admin/config` | Полная админка (заголовок `X-Admin-Token`) |

Данные хранятся в `proxy/data.json` (создаётся автоматически).

## Бесплатные/почти бесплатные VPS с рф-локацией

Бесплатных российских VPS «навсегда» практически не существует, но есть
варианты, где можно получить сервер бесплатно на срок от 1 до 12 месяцев:

1. **Yandex Cloud** — грант ~4000 ₽ новым пользователям (хватит на 2–3 месяца
   самой дешёвой VM) + бесплатный тариф для некоторых сервисов. yandex.cloud
2. **Timeweb Cloud** — грант новым пользователям по промо, VPS от ~150 ₽/мес.
3. **VK Cloud** — стартовый грант новым аккаунтам.
4. **Aeza / VDSina** — периодические промо-акции с бесплатным тестовым периодом.
5. Если локация не принципиальна для теста — любой бесплатный Tier
   (Render / Railway / Fly.io) подойдёт для проверки API-части, но **русские
   плееры будут гео-блокировать прокси не из РФ**. Для озвучек нужен именно
   российский IP.

Самый дешёвый рабочий вариант: VPS в РФ за ~150–200 ₽/мес (1 GB RAM хватит).

## Запуск на VPS (Node.js ≥ 18)

```bash
# Авто-установка (Ubuntu): Node 20 + pm2 + nginx + HTTPS
bash deploy.sh ваш-домен.ру          # с доменом → https
bash deploy.sh                        # без домена → http://IP:8080
```

Вручную:

```bash
git clone <репозиторий> && cd proxy
PORT=8080 ADMIN_TOKEN=ваш_пароль node server.js   # или через pm2:
PORT=8080 ADMIN_TOKEN=ваш_пароль pm2 start server.js --name ru-proxy
```

## Docker

```bash
docker build -t ru-proxy .
docker run -d -p 8080:8080 --name ru-proxy ru-proxy
```

## Nginx + HTTPS (рекомендуется)

Mini App работает по HTTPS, поэтому прокси тоже должен отдаваться по HTTPS:

```nginx
server {
    server_name ru-proxy.example.com;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_buffering off;          # важно для стриминга видео
        proxy_read_timeout 300s;
    }
    # ssl-сертификат через certbot: sudo certbot --nginx
}
```

## Подключение к приложению

1. **Админка** → «🌍 RU-Proxy» → вставить `https://ru-proxy.example.com` → Сохранить → Проверить.
2. Либо задать при сборке фронтенда: `VITE_RU_PROXY=https://ru-proxy.example.com npm run build`
   (адрес из админки имеет приоритет над env).

После этого у источников Kodik/Collaps/VideoCDN появится пометка «Через прокси»,
и они будут работать с любого IP.
