## 🌟 1. Краткое резюме проекта

**ZENOVA TMA** — это высокотехнологичный мультимедийный сервис нового поколения, работающий прямо внутри Telegram (Telegram Mini Apps / WebApp) на iOS, Android, macOS и Windows.

Сервис объединяет в одном интерфейсе три самых востребованных типа контента:

1. **Онлайн-кинотеатр 4K / Full HD**: Мировые новинки кино, культовые фильмы, топовые сериалы, аниме и мультфильмы с профессиональным дубляжом и поддержкой VPN. Каталог — миллионы тайтлов через TMDB API с русскими описаниями, постерами и рейтингами.
2. **Музыка 2.0 — миллионы ПОЛНЫХ треков**: Открытые легальные каталоги **Audius** и **Internet Archive** (поиск по миллионам записей, чарты недели, подборки под настроение), 24/7 HD-радиостанции (Европа Плюс, DFM, Record, Lo-Fi), фоновое воспроизведение, MediaSession (управление с экрана блокировки и наушников).
3. **КиноИИ (AI-подборщик)**: Интеллектуальный рекомендательный ассистент, подбирающий фильмы под настроение пользователя в формате диалога.

**Бонус-разделы**: журнал обновлений «Что нового», лента киноновостей с трейлерами (RuTube/YouTube), спортивная аналитика, премиум-магазин подписок.

## 💰 2. Экономика и Обоснование Стоимости (250 000+ ₽)

### А. Нулевые расходы на инфраструктуру (0 ₽ / мес)
* В классических проектах вам приходится платить от 10 000 до 40 000 ₽ в месяц за выделенные сервера (VPS/VDS), CDN-трафик, базы данных PostgreSQL и администрирование.
* **В ZENOVA архитектура полностью Serverless**: фронтенд размещается на бесплатном Vercel / Cloudflare Pages / GitHub Pages, видео отдаётся через внешние балансировщики, музыка — через открытые API (Audius, Internet Archive) и радиопотоки.
* **Чистая прибыль = 100% от выручки.**

### Б. Обязательная подписка (ОП) — главный генератор прибыли
* В сервис встроен модуль **Обязательной подписки (ОП)** на ваш Telegram-канал.
* До того как пользователь начнёт просмотр фильма, сервис вежливо и нативно требует подписаться на ваш Telegram-канал.
* **Рыночная стоимость живого подписчика в нише кино в Telegram:** от **25 до 45 рублей за 1 ПДП**.
* **Пример расчёта окупаемости:**
  * Трафик из TikTok / Reels / Shorts / Поиска Telegram: 1 000 заходов в день.
  * Конверсия в подписку: ~50% = **500 новых подписчиков ежедневно**.
  * За 1 месяц вы получаете: **15 000 живых подписчиков**.
  * Рыночная ценность этой базы: **15 000 × 30 ₽ = 450 000 рублей!**
  * Проект полностью окупает свою стоимость уже в **первый месяц работы** только за счёт прироста базы вашего канала.

### В. Прямая монетизация в сервисе
1. **Telegram Stars**: Прием платежей за VIP-подписку (2 дня / 5 дней / 7 дней / месяц / год — все тарифы и цены настраиваются из админ-панели). Работает по всему миру, без риска блокировки карт.
2. **Рекламные слоты и спонсорские баннеры**: В админ-панели настраивается показ закреплённых баннеров спонсоров.
3. **Продажа рекламы в привязанном Telegram-канале**: Канал с аудиторией 20 000 – 50 000 подписчиков приносит от 60 000 до 180 000 ₽ в месяц на рекламных постах через Telega.in и прямых рекламодателей.

## ⚖️ 3. Юридическая Чистота и Защита от Рисков

1. **Музыка — 100% легальна**: Используются только открытые каталоги Audius (треки размещают сами правообладатели-артисты) и Internet Archive (CC-лицензии, нетлейблы, концертные архивы с разрешения групп, общественное достояние). Плюс открытые радиопотоки FM-станций.
2. **Встроенный механизм Notice & Takedown (ст. 1253.1 ГК РФ, DMCA)**:
   * В админ-панели реализована вкладка `⚖️ Stop-лист (Takedown)`.
   * При поступлении любого обращения правообладателя администратор в 1 клик блокирует тайтл по ID или названию.
   * При попытке открытия заблокированного фильма пользователю выводится официальная юридическая заглушка правообладателя.
3. **Возрастной фильтр 18+ (ФЗ-436)**:
   * Эротический и взрослый контент защищён модальным окном подтверждения возраста 18+.
4. **Отсутствие персональных данных**:
   * Сервис не хранит паспорта, email и телефоны пользователей, что исключает нарушения 152-ФЗ («О персональных данных») и европейского GDPR.
5. **Безопасная передача**:
   * Исходный код очищен от персональных данных предыдущего владельца (чистый git author, нейтральные ссылки).

> ⚠️ **Примечание для покупателя**: видеовоспроизведение реализовано через сторонние встраиваемые плееры-балансировщики (как у 95% Telegram-кинотеатров). Хостинг видео не входит в комплект — ответственность за ссылки на контент несёт оператор балансировщиков. Механизм Takedown включён для оперативного реагирования на обращения правообладателей.

## 🛠️ 4. Технические Особенности и Стек

### Стек
* **Фронтенд**: React 18 + TypeScript + Vite 6 (сборка за ~0.6 сек, бандл ~124 КБ gzip).
* **Состояние**: Zustand (два стора: приложение + музыка).
* **Роутинг**: react-router-dom (HashRouter — идеально для Telegram WebApp).
* **Стилизация**: Модульный CSS на дизайн-токенах, **две полноценные темы** — тёмная «Obsidian & Rose Gold» и светлая «Rose Blush», glassmorphism, 60 FPS анимации, safe-area под вырезы iPhone.
* **Интеграции**: Telegram WebApp SDK (haptic, theme, backButton, облачное хранилище), TMDB API, Audius API, Internet Archive API, iTunes Radio / hostingradio.

### Кинотеатр
* Каталог TMDB: тренды, премьеры, топы, 15+ жанровых подборок, мгновенный поиск, фильтры и пагинация.
* 5 видеосерверов («Плеер 1–5») с русскими озвучками и переключением в 1 клик.
* Трейлеры RuTube/YouTube, дневник просмотра (статусы + личные оценки 1–10), избранное, история.
* КиноИИ: подбор фильмов по настроению через диалог.

### Музыка 2.0
* **Полные треки** (не превью!) из открытых каталогов Audius + Internet Archive — миллионы записей.
* «Моя Волна» с настроениями: каждое настроение — свой жанр/плейлист (Electronic, Lo-Fi, Deep House, Rock, Кинематографичные).
* Бесконечная прокрутка списков, живой поиск по двум каталогам одновременно.
* 6 HD-радиостанций 24/7 с автоматическим фолбэком потоков.
* Премиум-плеер: полноэкранный режим с drag-перемоткой, скорость 0.8–1.5x, повтор, шаффл, очередь, лайки (синхронизация между устройствами через облако), MediaSession.
* Фоновое воспроизведение: музыка продолжает играть при навигации по каталогу.

### Админ-панель
* Вход без пароля: автоматическое распознавание @username Telegram-администратора.
* Управление каналом Обязательной Подписки (смена ссылки, включение/выключение в 1 клик).
* Управление тарифами, ценами и реквизитами оплаты (Telegram Stars / карта).
* Управление баннерами и уведомлениями.
* Выдача VIP-доступа пользователям по нику и генерация персональных токенов.
* Реестр стоп-листа Notice & Takedown.
* Все настройки синхронизируются через serverless cloud sync — изменения применяются у всех пользователей мгновенно, без передеплоя.

### Журнал обновлений
* Встроенная страница «Что нового» — карточки версий с цветными строками изменений (Новое/Улучшено/Исправлено/Удалено), фильтрами и реакциями. Покупатель добавляет новые записи одним блоком данных (`src/data/changelog.ts`).

## 🚀 6. Пошаговая Инструкция по Приёму Проекта (5 Минут)

После покупки перенастройка занимает ровно 5 минут:

1. **Приём бота в Telegram**:
   * Откройте `@BotFather` в Telegram.
   * Предыдущий владелец отправит вам бота через `/mybots` → `[Ваш бот]` → `Bot Settings` → `Transfer Ownership`.
   * Примите передачу владения.
   * В `@BotFather` сгенерируйте новый API-токен командой `/revoke`.
2. **Приём GitHub репозитория**:
   * Сообщите ваш GitHub логин. Предыдущий владелец передаст репозиторий через `Settings` → `Transfer ownership`.
3. **Установка своего никнейма администратора**:
   * В файле `src/services/accessControl.ts` укажите ваш никнейм в Telegram:
     ```typescript
     export const MASTER_ADMINS = ['ВашНикнеймВTelegram'];
     ```
   * Сделайте `git push` — сайт обновится автоматически за 30 секунд.
4. **Привязка вашего Telegram-канала**:
   * Откройте сервис в Telegram.
   * Перейдите во вкладку Профиль → Админ-панель → `📢 Telegram-канал`.
   * Введите ссылку на ваш канал и включите Обязательную подписку!
